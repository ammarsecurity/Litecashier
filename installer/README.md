# Litecashier — مثبّت Windows 11 (جهاز واحد)

مثبّت يجهّز **الخادم + خادم الطباعة + الواجهة** على حاسبة Windows 11، ويُنشئ أيقونة **Litecashier** على سطح المكتب.

> **قاعدة البيانات يدوية:** شغّل MySQL من XAMPP (أو أي MySQL) بنفسك. المثبّت لا يضمّن ولا يشغّل MariaDB.

## للمستخدم النهائي

1. شغّل **MySQL** من لوحة XAMPP (أو أي MySQL).
2. انسخ `Litecashier-Setup.exe` وثبّته.
3. أثناء التثبيت أدخل بيانات قاعدة البيانات (Host / Port / User / Password / Database) — الافتراضي: `localhost` / `3306` / `root` / بدون كلمة مرور / `pos`.
4. افتح أيقونة **Litecashier** على سطح المكتب.
5. سيفتح المتصفح على: `http://localhost:5189`

> لا تحتاج إنشاء القاعدة يدوياً: النظام ينشئها إن لم تكن موجودة، أو يحدّثها إن كانت موجودة مسبقاً.

### إعدادات قاعدة البيانات (ثابتة في البرنامج)

| الحقل | القيمة |
|--------|--------|
| Server | `localhost` |
| Port | `3306` |
| Database | `pos` |
| User | `root` |
| Password | *(فارغ)* |

### تسجيل الدخول الافتراضي (أدمن النظام)

| الحقل | القيمة |
|--------|--------|
| الهاتف | `07830200030` |
| كلمة المرور | `12345678` |

> لا تُضاف بيانات تجريبية. الأدمن يُنشأ مع الـ migrations عند أول تشغيل ناجح، ثم تنشئ الحساب التجاري من صفحة الحسابات.

### في حال وجود مشكلة

- راجع مجلد السجلات: `C:\ProgramData\Litecashier\Logs`
- تأكد أن MySQL يعمل وأن قاعدة `pos` موجودة
- المنافذ: `3306` (MySQL)، `5189` (النظام)، `5000` (الطباعة)

**ملاحظة:** الإصدار 1.0.26 — أثناء التثبيت تُطلب بيانات MySQL (Host / User / Password / Database). النظام ينشئ القاعدة إن لم تكن موجودة أو يحدّثها إن وُجدت. عند التحديث ثبّت فوق النسخة الحالية بدون إلغاء تثبيت. المثبّت يوقف Litecashier / POS / PrintServer تلقائياً قبل استبدال الملفات.

**الترخيص:** ضع رابط سيرفر التراخيص في `config/appsettings.Production.json` تحت `License:BaseUrl` قبل بناء المثبّت. شغّل `license_server` وولّد أكواد عبر `New-LicenseKey.ps1`.

### الوصول من حاسبة ثانية (نفس الراوتر)

1. على **حاسبة السيرفر**: شغّل Litecashier واتركه مفتوحاً.
2. اعرف IP السيرفر (`ipconfig` → IPv4)، مثال: `192.168.1.10`
3. على **الحاسبة الثانية** افتح المتصفح:
   ```
   http://192.168.1.10:5189
   ```
4. المثبّت يفتح جدار الحماية للمنافذ `5189` (النظام) و `5000` (الطباعة) تلقائياً.
5. يفضّل تثبيت IP ثابت للسيرفر من إعدادات الراوتر (DHCP reservation).

> الطباعة من الحاسبة الثانية تمر عبر Print Server على السيرفر (نفس الـ IP، منفذ 5000). الطابعة يجب أن تكون معرّفة على حاسبة السيرفر.

### تحديث بدون فقدان البيانات

1. شغّل المثبّت الجديد فوق التثبيت الحالي (لا تضغط «إلغاء التثبيت»).
2. المثبّت يوقف النظام تلقائياً (`Litecashier.exe` / `POS.exe` / `PrintServer.exe`) — لا حاجة لملف الإيقاف يدوياً.
3. بعد انتهاء التثبيت افتح Litecashier من الأيقونة.

> ملف **إيقاف Litecashier** ما زال متوفراً إن احتجت إغلاق النظام يدوياً خارج التحديث.

### إلغاء التثبيت

من **إعدادات Windows → التطبيقات → Litecashier → إلغاء التثبيت**

## لبناء المثبّت (جهاز التطوير)

### المتطلبات

| الأداة | الإصدار |
|--------|---------|
| .NET SDK | 8.0+ |
| Node.js | 18+ |
| Inno Setup | 6.x |

تثبيت Inno Setup عبر winget:

```powershell
winget install JRSoftware.InnoSetup --accept-package-agreements --accept-source-agreements
```

### خطوات البناء

```powershell
cd installer
powershell -ExecutionPolicy Bypass -File .\build-installer.ps1
```

الملف الناتج:

```
installer/output/Litecashier-Setup.exe
```

### خيارات البناء

```powershell
# بدون إعادة بناء الواجهة
.\build-installer.ps1 -SkipFrontendBuild

# تجهيز staging فقط بدون Inno Setup
.\build-installer.ps1 -SkipInstallerCompile
```

### ماذا يفعل المثبّت؟

```
C:\Program Files\Litecashier\
├── Litecashier.exe      ← أيقونة سطح المكتب
├── POS\                 ← API + واجهة Vue (wwwroot/app)
└── PrintServer\         ← خادم الطباعة (منفذ 5000)
```

السجلات: `C:\ProgramData\Litecashier\Logs`

### تدفق التشغيل

1. شغّل MySQL يدوياً (XAMPP) وتأكد من وجود قاعدة `pos`
2. **Litecashier.exe** يشغّل PrintServer ثم POS
3. يفتح المتصفح على الواجهة
