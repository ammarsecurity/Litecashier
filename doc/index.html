Getting Started

Setting Up the Cashier System

Frontend Setup:

  1. Install Node.js.
  2. Open the "cashier_front" folder in Visual Studio Code.
  3. Execute the following command to install dependencies:
$ npm install

Modify the API baseURL

Navigate to cashier_front/src/api/index.js and update the baseURL:

            import axios from "axios";
            var token = localStorage.getItem("token");
            export const HTTP = axios.create({
                baseURL: `https://your-backend-api-url.com`, // Replace with your own API baseURL
                headers: {
                    Authorization: 'Bearer ' + token,
                }
            });

Backend Setup:

  1. Open the "cashier_back" folder in Visual Studio.
  2. Press Ctrl + Shift + B to load the required libraries for execution.

Modify the Connection String

Navigate to cashier_back/POS/appsettings.json and update the connection string:

            "ConnectionStrings": {
               "WebApiDatabase": "Server=yourlocalhost;Database=xxxxx;MultipleActiveResultSets=true;Trusted_Connection=True;TrustServerCertificate=True;"
            },

Access the Application

After completing the configuration and executing the previous steps, you can access the application in your web browser:

  • Frontend: http://localhost:8080 (default Vue.js dev server port)
  • Backend API: https://localhost:5001 or http://localhost:5000 (default ASP.NET Core ports)
  • Swagger Documentation: https://localhost:5001/swagger

Important Notes:

  • Replace "your-backend-api-url.com" in the baseURL with your actual backend API URL.
  • Replace "yourlocalhost" and "xxxxx" in the connection string with your database server and database name, respectively.
  • Make sure both frontend and backend servers are running before accessing the application.

Running the Cashier System

Backend Setup

  1. Open the cashier_back/POS folder in Visual Studio 2022.
  2. Restore NuGet packages (usually done automatically).
  3. Update the connection string in appsettings.json.
  4. Run the application (Press F5 or click Run).
  5. The backend API will start on https://localhost:5001 or http://localhost:5000.

Frontend Setup

After completing all the modifications and running the backend, execute the following command in Visual Studio Code terminal to start the frontend development server: 

$ npm run serve

The frontend will start on http://localhost:8080 (or the next available port).

How to Use

Login to Cashier System

First Step:

Test credentials for Admin User to add Commercial users:

Phone Number: 07830200030

Add Commercial Account

Logout and then check the new Commercial account.


You can use the Commercial account as a sales area, or through it, you can create point-of-sale accounts or price reader accounts. Additionally, within the Commercial account, there is a page for all your sales or the sales associated with your point-of-sale accounts.

The first page in the Commercial account is the Dashboard.

By clicking above in the navbar, you can navigate to different sections.

POS Page

Through the POS page, you can quickly create invoices. Also, in case a product is unavailable, you can add the items you need directly from the same page.

Items Page

Through the Items page, you can add, edit, and delete items.

Accounts Page

Through the Accounts page, you can add, edit, and delete accounts (POS and Price Reader accounts).

Reports Page

Through the Reports page, you can view the sales reports for the current day, the current month, or the current year. You can also view advanced reports including profit reports, top-selling items, sales by category, sales by employee, and low stock items.

Price Reader Page

Through the Price Reader page, you can view just the item price by scanning the barcode.

On the same Login page, you can access the system as Admin, Commercial, Point of Sales, or Price Reader user.
